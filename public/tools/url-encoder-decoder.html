URL encoder and decoder

Encode text for safe use in a URL, or decode a percent-encoded string.

About this tool

Encoding uses encodeURIComponent, which escapes reserved characters such as spaces, ampersands, equals signs and slashes, so encode individual values rather than a whole URL. Decoding uses decodeURIComponent.
