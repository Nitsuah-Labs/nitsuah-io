JSON formatter and validator

Paste JSON to validate it and get a cleanly indented version.

About this tool

The input is parsed with the browser's JSON parser and re-printed with two-space indentation; the error message comes from the browser and usually points at the position of the problem. JSON does not allow comments, trailing commas or single quotes. Nothing is sent anywhere.

Free, runs in your browser, nothing is uploaded or tracked. More free tools.
