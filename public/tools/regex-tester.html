Regex tester

Try a regular expression on sample text and see each match with its position.

About this tool

Patterns use JavaScript regular expression syntax, which differs from other languages in places such as lookbehind support and named groups. Matching stops at 1000 matches. Very complex patterns on long text can be slow because the browser runs them on this page.

Free, runs in your browser, nothing is uploaded or tracked. More free tools.
