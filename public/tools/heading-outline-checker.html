HTML heading outline checker

Paste a page's HTML to see its heading structure and find accessibility problems such as skipped heading levels.

About this tool

Screen reader users navigate by headings, so levels should not skip (for example h2 straight to h4), and a page normally has one h1. Pasted HTML is parsed in your browser and never sent anywhere. This checks heading structure only, not whether headings are well written.

Free, runs in your browser, nothing is uploaded or tracked. More free tools.
