Vague link text checker

Paste HTML to find links whose text does not say where they go.

About this tool

WCAG asks that the purpose of a link can be understood from its text (success criterion 2.4.4). Screen readers can list all links on a page, where "click here" is meaningless. This checks the text, aria-label and image alt text of links using simple pattern matching against a short list of vague phrases, so it will miss other vague wording and unusual markup. Nothing is uploaded.
